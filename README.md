# Expense Tracker (Java)

A simple console-based Expense Tracker application built using Java.

## Features
- Add Income & Expense
- View Transactions
- Show Balance
- Save data to file
- Load data from file

## Technologies Used
- Java
- OOP Concepts
- File Handling

## How to Run

1. Compile:
javac ExpenseTracker.java

2. Run:
java ExpenseTracker
